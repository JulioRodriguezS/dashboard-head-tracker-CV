# CV Corporativo Inteligente + Heatmap & KPIs Tracker

Una arquitectura completa para desplegar un currículum web de alto impacto corporativo, acompañado de un sistema de analíticas personalizado (SaaS) que registra visitas, geolocalización y genera mapas de calor interactivos utilizando Supabase y JavaScript nativo.

## Características Principales

* **CV Optimizado para Reclutadores:** Diseño basado en metodologías de ventas corporativas, con exportación a PDF de una sola página y en blanco y negro (mediante `html2pdf.js`).
* **Rastreador Silencioso:** Script ligero (`heatmap-tracker.js`) con *throttling* y envío por lotes para no afectar el rendimiento de la memoria del navegador.
* **Dashboard de Analíticas:** Visor independiente (`dashboard.html`) construido con Canvas HTML5 y Chart.js para visualizar el tráfico y el comportamiento del usuario en tiempo real.
* **Backend Serverless:** Infraestructura de base de datos impulsada por Supabase (PostgreSQL) con políticas de seguridad de nivel de fila (RLS).

## 1. Configuración de la Base de Datos (Supabase)

1. Crea un proyecto gratuito en [Supabase](https://supabase.com/).
2. Dirígete al **SQL Editor** y ejecuta el siguiente script para crear las tablas y habilitar la seguridad:

```sql
-- Crear tabla de analíticas
CREATE TABLE kpis (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    user_id TEXT, ip TEXT, version TEXT, city TEXT, region TEXT, region_code TEXT,
    country TEXT, country_name TEXT, country_code TEXT, country_code_iso3 TEXT,
    country_capital TEXT, country_tld TEXT, continent_code TEXT, in_eu BOOLEAN,
    postal TEXT, latitude NUMERIC, longitude NUMERIC, timezone TEXT, utc_offset TEXT,
    country_calling_code TEXT, currency TEXT, currency_name TEXT, languages TEXT,
    country_area NUMERIC, country_population NUMERIC, asn TEXT, org TEXT,
    vendor TEXT, cookies BOOLEAN, language TEXT, platform TEXT, user_agent TEXT
);

-- Crear tabla para mapas de calor
CREATE TABLE heatmap_data (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    session_id TEXT NOT NULL, url TEXT, screen_width INTEGER, screen_height INTEGER,
    coordinates JSONB NOT NULL
);

-- Habilitar Row Level Security (RLS)
ALTER TABLE kpis ENABLE ROW LEVEL SECURITY;
ALTER TABLE heatmap_data ENABLE ROW LEVEL SECURITY;

-- Políticas de seguridad: Permitir escritura pública, restringir lectura
CREATE POLICY "Permitir inserciones anonimas kpis" ON kpis FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "Permitir inserciones anonimas heatmap" ON heatmap_data FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "Permitir lectura anonima heatmap" ON heatmap_data FOR SELECT TO anon USING (true);
CREATE POLICY "Permitir lectura anonima kpis" ON kpis FOR SELECT TO anon USING (true);
